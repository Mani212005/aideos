2. Code Verification & Root Cause Characterization

CODE EVIDENCE

2.1 The "Successfully built 0 video scenes" Bug

When the user inputs plain prose (such as the what-is-jepa script) and clicks "Auto-Build Scenes from Script":

1. Parser Discards Untagged Lines

In backend/scriptIntake.ts (lines 268-368), parseClaudeScript() checks lines for [VISUAL] or [NARRATION] tags. When none exist, currentBeatType is null, and body lines are completely ignored (line 361). segments evaluates to [] (0 segments, 0 shots, 0 nodes). 

// backend/scriptIntake.ts:361
if (currentBeatType && line) {
  bodyLines.push(line); // Skipped if untagged!
}
2. UI Reports Fake Success & Masks State

In editor/src/components/ScriptEditor.tsx (lines 450-490), the frontend receives shots: [] with HTTP 200. It falls back to keeping the previous film shots (data.shots.length > 0 ? data.shots : film.shots), and triggers a green success toast: 

// ScriptEditor.tsx:486
setStatusMsg({
  type: "success",
  text: `Successfully built ${data.shots.length} video scenes...`
}); // Prints: "Successfully built 0 video scenes..."

2.2 The Connected Agent & Telemetry Gap

MCP IS STRICT AGENT-PULL

backend/mcp/server.ts operates over stdio. The agent must pull tools. The server cannot initiate a push or wake up the external agent process when a user clicks a button in the browser.

TMUX DISPATCH FAILS SILENTLY

backend/agentPrompter.ts checks for tmux has-session -t aideos. Since modern coding agents (Firstmate crewmate, Antigravity, Claude Code) do not run in this tmux session, it writes to .aideos_task.md which no agent monitors.

AGENT TRACE IS MOCKED

AgentActivityInspector.tsx renders defaultSteps: a static array mentioning "FlashAttention-3" and "10:48:02 AM". It has zero props, zero websocket/SSE, and no connection to real tool execution.

3. Target Architecture: Unified Agent Bridge Hub

APPROVED ARCHITECTURE

With the Captain's approval of the Hybrid Multi-Channel Dispatcher and Automatic Director LLM Prose Transformation, the Aideos Agent Bridge is architected as follows:

1 HYBRID OUTBOUND DISPATCH

When a user triggers an action (e.g. "Auto-Build", "Voiceover Ready", "AI Edit Request"):

  • Firstmate Inbox: Writes mission message (.msg) to steering inbox for instant worker wakeup.
  • MCP Job Queue: Enqueues task for connected MCP agents (aideos_get_pending_tasks).
  • In-Process Fallback: Executes in-process Gemini model call if no external agent claims the task within 10s.
2 DIRECTOR LLM PROSE AUTO-TRANSFORM

When untagged prose is passed to Auto-Build:

  • Director LLM Pipeline: Automatically structures raw prose into Claude screenplay segments with timestamps, [VISUAL], and [NARRATION] beats.
  • Metaphor & Primitive Binding: Selects appropriate visual primitives (MatrixGrid, TokenStrip, StatCounter).
  • Zero-Leakage Narration: Produces clean dialogue blocks for speech synthesis.
3 UNIFIED LIVE SSE TRACE BUS

Real-time telemetry streamed directly to the top-bar Agent Trace panel:

  • SSE Stream: GET /api/agent/trace broadcasts real tool executions and reasoning steps.
  • Unified Visibility: Streams both external agent tool calls and background pipeline jobs (TTS, B-roll, Remotion).
  • Dynamic Inspector: Replaces the mock component with live timers and status indicators.
