**Property-based testing status**: aideos has **no property-based testing library** in `package.json`, `editor/package.json`, or `native/Cargo.toml`, and none is needed yet: the pure invariants tested so far are covered by a zero-dependency seeded runner, `backend/testSupport/propertyTest.ts` (mulberry32, `forAll`, failing seed and input in the message, `AIDEOS_PROPERTY_SEED=<n>` replays one case). It is used by `backend/timeFrameArithmetic.property.test.ts` (shot timeline tiling and half-frame drift bound, millisecond grid, delivered length with the end card, caption placement clamping) and `backend/timeline/layerIds.property.test.ts` (layer and clip id uniqueness and references over random edit sequences). Older invariant and randomized tests use handwritten deterministic loops (for example `backend/journeys/character_retarget.journey.ts` over random proportions, `backend/editPlanner/ai_edit_invariants.test.ts`, `backend/editPlanner/phase3_invariants.test.ts`, and `backend/pipeline/agent_director_invariants.test.ts`). Recommended libraries if adopting one later (do not add without explicit approval): `fast-check` for TypeScript/Node and `proptest` for Rust.

**Expect testing status**: `backend/testSupport/expectFile.ts` compares real captured output with reviewed files under `test_fixtures/expect/` (`AIDEOS_UPDATE_EXPECT=1` rewrites them, review the git diff before committing). Covered: Render IR (`backend/renderIr/emit.expect.test.ts`, long and reel), film JSON as written by the film store (`backend/pipeline/filmJson.expect.test.ts`), and shot timeline, delivered length and caption placement results (`backend/timelineResults.expect.test.ts`).

## Aideos verification commands and independent review

- **Static checks (fast, docs-safe)**: `npm run ci -- static`
- **Targeted Node unit test**: `node --import tsx --import ./backend/testSupport/fixtureVideosDir.ts --test --test-concurrency=1 <test-file>`
- **Full Node unit & fixture job**: `npm run ci -- unit`
- **Targeted journey**: `node --import tsx --import ./backend/testSupport/fixtureVideosDir.ts --test --test-concurrency=1 backend/journeys/<name>.journey.ts`
- **Native Rust tests**: `cargo test --locked --manifest-path native/Cargo.toml`
- **Legacy goldens (Linux)**: `npm run ci -- legacy`
- **Independent code/PR review pipeline**: `no-mistakes` (separate reviewer models inspect the diff and lint/test results before PR merge)
- **Independent video review pipeline (for film packages)**: `aideos review <slug>` + `aideos all-check <slug>` (Gemini 3.8 Flash via `agy`)
