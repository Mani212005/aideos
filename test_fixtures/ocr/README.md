# Numeric OCR fixtures

These grayscale rasters contain only the generic numerals `2,500` and `30,000` on a plain canvas. They preserve the rendered JetBrains Mono glyphs and sampling that sparse-text Tesseract misreads as `2,900` and `50,000`. The fixed pixels make the regression independent of font installation and browser rasterization. They contain no film layout, narration, metadata or other personal assets.
